===========================================
🚀 一键推送到 GitHub (最终版)
===========================================

复制下面这行完整的命令到 PowerShell 执行:

```powershell
$branch = git branch --show-current; if (-not $branch) { git branch -M main }; git remote add origin https://github.com/YOUR_GITHUB_USERNAME/emby-gpui-client.git 2>$null; git push -u origin main --force
```

替换 `YOUR_GITHUB_USERNAME` 为你的实际 GitHub 用户名即可!

示例:
```powershell
git remote add origin https://github.com/zhangsan123/emby-gpui-client.git
git push -u origin main --force
```

完成后的结果:
✅ 代码自动上传到 GitHub
✅ Actions 工作流自动开始运行
✅ 5-10 分钟后可以下载测试包
✅ URL: https://github.com/YOUR_GITHUB_USERNAME/emby-gpui-client

===========================================
如果 gh CLI 已安装，也可以用这个简化版:
===========================================

```powershell
gh repo create emby-gpui-client --public --source=. --push --description "GPU-accelerated Emby client"
```
